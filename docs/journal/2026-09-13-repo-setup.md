## 3. Находки

**FIND-1 · bun build --target=browser НЕ ловит node-зависимости — он их молча подменяет**
Замер 13.09: файл с `import { readFileSync } from "node:fs"` собрался под
`bun build --target=browser` с кодом 0, а в выводе оказалось `var {readFileSync} = (() => ({}))`
— то есть пустой объект. В Workers это упало бы в рантайме, а сборка была зеленой.

Работающий гейт — `esbuild --platform=neutral`: он не резолвит ни одного встроенного модуля и
отдает `Could not resolve "node:fs"` с ненулевым кодом. Это и стоит в
`scripts/check-core-portability.mjs`.

Bun остается в проекте как ВТОРОЙ РАНТАЙМ (`pnpm smoke:bun` реально исполняет core), но не как
проверка переносимости.

**FIND-2 · pnpm 11 игнорирует pnpm.onlyBuiltDependencies в package.json — и молчит об этом**
Настройка переехала в `pnpm-workspace.yaml`. Оставленная в `package.json`, она не читается:
`[WARN] The "pnpm" field in package.json is no longer read by pnpm`.

Цена ошибки тихая: `esbuild` не распаковывает свой бинарник (`node_modules/.bin/esbuild` нет),
а `lefthook` не ставит git-хуки. Оба отказа выглядят как предупреждение при установке, а не
как ошибка, и обнаруживаются много позже.

**RISK-1 · Источник каталога эндпоинтов не подтвержден — вся Фаза 2 стоит на нем**
Требования (§6–§9) предполагают, что официальную коллекцию Braze для Postman можно выгрузить
скриптом. Проверено 13.09 — не подтверждено:

- `https://www.postman.com/api/collections/braze/` → 404
- `https://api.github.com/repos/braze-inc/braze-docs` → 404 (репозитория с таким именем нет)
- документер-страница отдает HTML-приложение, а не JSON коллекции

Сами требования это допускают (§8: «exact mechanics depend on how reliably the public Postman
collection can be exported»). Вывод: **первым пунктом Фазы 2 идет разведка источника**, и у
фазы должна быть развилка — если коллекция не выгружается без токена Postman, каталог
собирается из другого источника (ручной экспорт коллекции, либо страницы документации Braze).
План не имеет права молча закладываться на хороший случай.

  §43/§44 — это первое, что упрется в Фазе 1.
- Варианты: **A** как в требованиях — терминал получает человеческий вывод, конвейер получает
  JSON, `--json` и `BRAZE_OUTPUT=json` всегда дают JSON · **B** JSON всегда, человеческий вывод
